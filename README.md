# InnovateFund - Web3 Crowdfunding Platform

InnovateFund คือแพลตฟอร์มระดมทุนแบบกระจายศูนย์ (Decentralized Crowdfunding) ที่ทำงานบนบล็อกเชน Ethereum ผ่าน Smart Contract เพื่อความโปร่งใสและปลอดภัย

**🔗 Live Demo:** https://supachai-sungsirin.github.io/InnovateFundCampaign/

## 🌟 ฟีเจอร์หลัก (Features)
- สร้างโครงการระดมทุนได้ไม่จำกัด (ใช้ Factory Pattern)
- กำหนดเป้าหมายและระยะเวลาการระดมทุนได้อย่างอิสระ
- ระบบจ่ายเงินตามระยะงาน (Milestone-based fund release)
- ผู้สนับสนุนมีสิทธิ์โหวตอนุมัติการจ่ายเงินในแต่ละเฟส
- สามารถขอคืนเงิน (Refund) ได้หากระดมทุนไม่สำเร็จตามเป้า
